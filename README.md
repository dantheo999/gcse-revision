# GCSE Revision Plan

A revision timetable for UK GCSEs that runs in the browser on a phone or tablet:

- Weighted sessions across subjects, from mock prep through to the summer exams
- A "Tonight" card with steps and a timer, tick-offs, a week view and progress tracking
- Accounts that sync each person's plan across devices
- Study groups: friends keep their own plans but line up core subjects on "together nights"

It's a single static page (`index.html`) backed by [Supabase](https://supabase.com) for accounts and storage.
Hosted with GitHub Pages.

See [SETUP.md](SETUP.md) to set up your own copy. With `config.js` left empty, the app works on one device without accounts.
